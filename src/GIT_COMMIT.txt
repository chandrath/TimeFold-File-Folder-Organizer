feat: Add File Organizer by Date - Production-ready .NET GUI application

Initial release of File Organizer by Date, a Windows Forms application built with .NET 10 SDK that automatically organizes files into month-year folders based on their Modified Date.

Features:
- Portable application that operates in the folder where the executable is located
- Groups files by Modified Date (LastWriteTime) into "Month YYYY" format folders
- Creates organized folder structure: Sorted_YYYY-MM-DD_HHMMSS with month-year subfolders
- Automatic conflict resolution with safe filename renaming (e.g., file_(1).pdf)
- Optional top-level folder inclusion (moves folders without touching contents)
- Real-time progress tracking with detailed status updates
- Comprehensive CSV logging of all operations
- Modern GUI with three-screen workflow (Preview → Progress → Completion)
- Single-file executable deployment ready

Technical Details:
- Built with .NET 10 SDK targeting Windows (net10.0-windows)
- Windows Forms GUI with async/await for non-blocking operations
- Clean architecture with separation of concerns (Models, Services)
- Production-ready error handling and user feedback
- Self-contained single-file executable support

Project Structure:
- FileOrganizer.csproj - Project configuration
- Program.cs - Application entry point
- MainForm.cs - Main GUI form with three panels
- Models/ - Data models (FileItem, OrganizationResult)
- Services/ - Business logic (FileOrganizerService, CsvLogger)

The application is ready for use and can be deployed as a single portable executable.
